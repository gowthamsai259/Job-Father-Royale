# Job-Father-Royale
Find, save, and apply to jobs.

## Local service routing

The frontend uses same-origin paths such as `/lp/auth/sync-user`. During local
development, Vite proxies `/lp` directly to the standalone auth service at
`http://localhost:8001` and removes the `/lp` prefix before forwarding.

There is no separate API gateway. In production, the frontend host can use a
Vercel rewrite for the same `/lp/*` paths. Set `AUTH_SERVICE_URL` in the
frontend environment when the local auth-service URL is different.

## Authentication service

`auth-service/backend` is the reusable login backend. Google OAuth is handled
by Supabase Auth, and `POST /auth/sync-user` verifies the Supabase access token
before upserting the profile. The profile `id` is the Supabase Auth user UUID,
which is stable for the user and is not generated by the frontend.
